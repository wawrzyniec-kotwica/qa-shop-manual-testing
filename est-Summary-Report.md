# Test Summary Report – QA SHOP

## 1. Project Overview

- **Project:** QA SHOP
- **Application:** SauceDemo
- **Testing Type:** Manual Testing
- **Browser:** Safari
- **Project Status:** In Progress

## 2. Testing Scope

The testing covered the following functionalities:

- User login and authentication
- Product listing and sorting
- Adding and removing products from the cart
- Shopping cart functionality
- Checkout process
- Checkout form validation
- Logout functionality

## 3. Testing Results

A total of 18 test cases were documented.

- 16 test cases: PASS
- 1 test case: FAIL
- 1 test case: N/A

One defect was identified during testing.

## 4. Identified Defect

**BUG-001 – Order can be completed with an empty shopping cart.**

The application allows the user to complete the checkout process without any products in the shopping cart.

- Severity: High
- Priority: High
- Status: Open – Retest required

## 5. Limitations

- Product quantity modification is not available in the tested application.
- Testing was performed manually in Safari.
- Results apply to the tested environment.

## 6. Final Conclusion

The main shopping functionalities were tested.

Most documented test cases passed. However, one high-priority defect was identified in the checkout process.

The project remains in progress until the identified defect is retested and the final results are verified.
