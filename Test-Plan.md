# Test Plan – QA SHOP

**Project:** QA SHOP  
**Application:** SauceDemo  
**Testing Type:** Manual Testing  
**Version:** 1.0  
**Status:** In Progress

## 1. Test Objective

The objective of this testing project is to verify the main functionalities of the SauceDemo shopping application and identify potential defects.

## 2. Test Scope

The following functionalities are included in testing:

- Login and authentication
- Product listing
- Product sorting
- Adding products to the cart
- Removing products from the cart
- Shopping cart functionality
- Checkout process
- Checkout form validation
- Order completion
- Logout functionality

## 3. Out of Scope

- User registration (the application provides predefined test accounts)
- Real payment processing
- Changing product quantities (not available in the tested application)

## 4. Testing Types

- Functional Testing
- Positive Testing
- Negative Testing
- Exploratory Testing
- Regression Testing

## 5. Test Environment

- Application: https://www.saucedemo.com/
- Browser: Safari
- Testing approach: Manual
- Platform: Web application

## 6. Entry Criteria

- Application is accessible.
- Test account credentials are available.
- Main application features are accessible.

## 7. Exit Criteria

- Planned test cases have been executed.
- Test results have been documented.
- Identified defects have been reported.
- Test execution summary has been prepared.

## 8. Deliverables

- Test Cases
- Bug Reports
- Test Execution Report
- Test Summary Report

## 9. Risks and Limitations

- The demo application may change or reset its data.
- Some functionalities may not be available.
- Results apply to the tested environment and browser.
