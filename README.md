# QA SHOP – Manual Testing Project

## About the Project
This is a practical manual software testing project created to demonstrate my skills as a Junior QA Tester.

The project focuses on testing an online shopping application: [SauceDemo](https://www.saucedemo.com/).

## Project Objectives
- Practice manual software testing.
- Create and execute test cases.
- Identify and report software defects.
- Perform positive and negative testing.
- Practice retesting and regression testing.
- Document test results and evidence.

## Test Scope
- User login and authentication
- Product listing and sorting
- Adding and removing products from the cart
- Shopping cart functionality
- Checkout process
- Form validation
- Logout functionality

## Testing Types
- Functional Testing
- Negative Testing
- Exploratory Testing
- Regression Testing

## Tools
- Safari
- Jira (practice)
- Postman
- SQL
- GitHub

The repository will contain:
